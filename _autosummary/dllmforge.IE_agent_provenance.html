dllmforge.IE_agent_provenance¶

Quote-first provenance: recover source_page from source_quote against a Docling index.

The LLM copies a verbatim quote. Page numbers are assigned in code by locating that quote in page-indexed elements (sections, tables, figures, prose).

Return the best matching index element for a quote, or None.

Long LLM quotes often concatenate a sentence + a table + more prose. Match the whole string first, then each paragraph, and prefer a table hit when the quote contains a markdown table.

dllmforge.IE_agent_provenance.apply_quote_provenance(obj: Any, index: Iterable[Dict[str, Any]] | None = None, metadata: Dict[str, Any] | None = None) → Any[source]¶

Walk a parsed extraction dict and fill source_page from source_quote.

If index is omitted, metadata['element_index'] or metadata['page_index'] is used. Unmatched quotes get quote_verified=False and source_page=None (do not keep a guessed page).
